# AutoCopy

AutoCopy — небольшая утилита для Windows, которая копирует выделенный мышью текст в буфер обмена. Выделите фрагмент, отпустите кнопку мыши и вставьте текст в нужное поле без нажатия `Ctrl+C`.

Приложение работает в системном трее. Его можно приостановить одним щелчком, настроить уведомления и исключить приложения, в которых автоматическое копирование не нужно.

## Возможности

- Копирование текста после выделения мышью, в том числе двойным и тройным щелчком, если их поддерживает исходное приложение.
- Пауза и возобновление работы щелчком по значку в трее. Значок показывает текущее состояние.
- Всплывающая подсказка и звук после успешного копирования. Каждый сигнал можно включить или отключить отдельно.
- Список исключений и команда добавления последнего активного приложения через меню трея. Проводник исключён по умолчанию.
- Необязательный автозапуск для текущего пользователя. По умолчанию он выключен.
- Переносимый запуск: настройки хранятся рядом с программой.

AutoCopy копирует обычный текст без форматирования. Приложение не ведёт собственную историю буфера; доступность системного журнала `Win+V` зависит от настроек Windows.

## Запуск

Для текущей сборки нужны **Windows x64** и **.NET 8 Desktop Runtime x64**. Приложению не требуются обязательная установка или права администратора.

Если готовая сборка недоступна, её можно создать из исходного кода по инструкции ниже. Запускайте `AutoCopy.exe` из папки сборки и сохраняйте остальные файлы рядом с ним, включая папку `Assets` со звуком.

После запуска значок появится в области уведомлений Windows; если его не видно, откройте меню скрытых значков.

1. Выделите текст мышью в приложении.
2. Отпустите кнопку мыши и дождитесь копирования.
3. Вставьте текст с помощью `Ctrl+V` или команды вставки.

AutoCopy ждёт системный интервал двойного щелчка, прежде чем проверить выделение. Это позволяет учесть последовательные щелчки; поэтому копирование происходит с небольшой задержкой. При стандартном значении Windows ожидание составляет 500 мс, не считая времени получения текста.

## Управление и настройки

**Левый щелчок** по значку приостанавливает или возобновляет работу. **Правый щелчок** открывает меню настроек и выхода. В меню также можно добавить последнее активное приложение в исключения.

В окне настроек доступны:

- всплывающая подсказка — включена по умолчанию;
- звук копирования — выключен по умолчанию;
- автозапуск вместе с Windows — выключен по умолчанию;
- добавление и удаление приложений в списке исключений.

Настройки сохраняются в `settings.json` рядом с `AutoCopy.exe` при их изменении. Папка программы должна быть доступна для записи. Если сохранить файл не удалось, приложение сообщит об этом; изменения продолжат действовать до выхода.

При включении автозапуска Windows запоминает путь к исполняемому файлу. После переноса папки запустите AutoCopy из нового расположения и включите автозапуск заново. Перед удалением программы отключите автозапуск в настройках, выйдите через меню трея и удалите папку приложения.

## Совместимость и ограничения

Базовое копирование, уведомления и звук проверены пользователем в нескольких программах. При этом AutoCopy использует Windows UI Automation, и результат зависит от того, предоставляет ли исходное приложение сведения о выделении. Работа во всех программах не гарантируется.

- Программа не отправляет `Ctrl+C` вслепую. Если получить выделение не удалось, текст не копируется.
- Явно обозначенные поля пароля должны пропускаться, но эта защита ещё не прошла полную ручную проверку и не распознаёт все поля с чувствительными данными. При необходимости используйте паузу или исключения.
- Поддержка Notepad++ не подтверждена; отдельного адаптера для его редактора нет. Проверка Obsidian отложена.
- Переносы строк в Блокноте требуют дополнительной проверки: в предварительном эксперименте UI Automation возвращала `CR` вместо исходных `LF`. AutoCopy намеренно не нормализует текст, полученный от приложения.
- Работа с приложениями, запущенными с повышенными правами, не гарантируется. Двойной и тройной щелчки, переключение фокуса и обработка ошибок также требуют дополнительных ручных проверок.

Перечисленные ограничения относятся к текущей версии и будут уточняться по мере проверки.

## Сборка из исходного кода

Нужен .NET 8 SDK. Из корня репозитория в PowerShell:

```powershell
dotnet publish src/AutoCopy/AutoCopy.csproj -c Release -r win-x64 --self-contained false -o publish/AutoCopy
```

Результат находится в `publish/AutoCopy/`. Эта сборка требует .NET 8 Desktop Runtime x64. Вариант `self-contained`, который не требует отдельно установленного runtime, пока не проверялся.
